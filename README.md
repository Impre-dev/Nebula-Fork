# Nebula Fork

Transparency-only fork of [Nebula](https://github.com/JustADumbPrsn/Zen-Nebula) for Zen Browser.

## What it keeps

- Glass / blur effect (`backdrop-filter`)
- Transparent browser background (see wallpaper through UI)
- Semi-transparent tab backgrounds
- Transparent sidebar
- Glass URL bar when open
- Transparent `about:*` pages
- Pseudo-backgrounds behind titlebar / urlbar / Ctrl+Tab (JS overlays)
- Gradient slider patched to allow 0 opacity

## What it removes (vs original Nebula)

- All animations (tab switch, loading, menu cascade, button hover, etc.)
- All glow / gradient effects on tabs and extensions
- Sound icon redesign
- MacOS-style window buttons
- Workspace button redesign
- Bookmarks autohide
- Findbar redesign
- Media controls / PiP redesign
- Tab folders styling
- Pinned extensions layout
- NoGaps mod
- Favicon color extraction

## Install

In Zen Browser → Sine → **Add** → type `Impre-dev/Nebula-Fork`
